## 🛡️ Fail-Safe Stage Demo Protocol (Zero Risk)
Conference Wi-Fi in high-density hackathon spaces frequently drops right when you take the stage. SeeForMe AI is engineered to guarantee 100% demo success:

1. **Before Going On Stage:**
   - Open **Settings** (gear icon).
   - Turn ON **"Stage Demo Mode (Fail-safe Pitch)"**.
   - If offline, the app seamlessly runs **Apple On-Device Neural Engine** anyway.
   - If presenting live API calls, ensure your SCX API Key and ElevenLabs API Key are saved in Keychain.
2. **Preset Demo Triggers:**
   - **Menu / Document:** Triggers instant local Vision OCR reading order.
   - **Currency:** Triggers AUD $20 note recognition with tactile window verification.
   - **Sydney Transit:** Triggers Martin Place Platform 2 Opal reader arrival.
   - **Enterprise Gauge:** Triggers analog 4.2 bar pressure gauge WHS audit.
3. **If Wi-Fi drops completely:**
   - Switch AI Provider in Settings to **"Apple On-Device AI (100% Private)"**.
   - Demo the entire app live without a cellular or Wi-Fi connection!
